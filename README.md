# Canvas

Instaladores do **Canvas** para Windows: um canvas compartilhado de telas, notas e imagens, para usar com amigos.

## Instalar

1. Baixe o `Canvas-Setup-X.exe` da [última versão](../../releases/latest) e execute. Não pede administrador.
2. O Windows pode avisar "O Windows protegeu seu PC", porque o instalador ainda não é assinado com certificado. Clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Abra o Canvas e cole o **link de convite** que você recebeu. Sem ele não há sala para entrar.

## Atualizações

O app procura versões novas ao abrir e a cada 4 horas, baixa em silêncio e avisa no canto da tela: **"Versão X pronta · Reiniciar"**. Se você só fechar o app, a atualização é instalada na próxima vez que abrir. No menu do botão direito há também **Procurar atualizações**.

Este repositório só guarda os instaladores. O atualizador do app lê o arquivo `latest.yml` da versão mais recente daqui.
